# てがかり仕分け

副業の明細（カード・銀行のCSV）を、副業の内容を手がかりに「事業候補・要判断・私用候補」に仕分け、本人が確定してCSVに書き出す、単一HTMLの整理ツールです。DMM 生成AI CAMP 第29回コンペの提出物です。

- 公開URL：https://wison-blip.github.io/tegakari-shiwake/
- 明細もプロフィールも、この端末のブラウザの中だけで扱います（外部への通信なし。ページの Content-Security-Policy で通信そのものを止めています）。
- 本ツールは明細の整理を補助するものです。経費への算入可否の判断は行いません。最終的な判断はご自身または税理士・税務署等にご確認ください。

## 交通の記録がある月の確認

乗車履歴・予定表・レシートがそろっている場合は、「元明細順に○件を確認」から始められます。同日・同額で摘要も同じ乗車には元行番号と何件目かを表示します。記録が後から届く場合は、乗車履歴や買い物のレシートを選んで再開できます。

同じ架空明細24件を幅390px・1280pxのブラウザで操作しました。全記録ありでは、仕分け一覧からCSV保存まで旧版の交通欄で29操作、旧版の最短経路で27操作、現行版で26操作でした。3回に分けて記録が届く場合は両版35操作です。用途はすべて1件ずつ選び、24行の最終区分を照合しました。制作側の自己評価は96／100点です。実利用者による所要時間と誤選択率は未測定です。
