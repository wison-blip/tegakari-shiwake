# てがかり仕分け

副業の明細（カード・銀行のCSV）を、副業の内容を手がかりに「事業候補・要判断・私用候補」に仕分け、本人が確定してCSVに書き出す、単一HTMLの整理ツールです。DMM 生成AI CAMP 第29回コンペの提出物です。

- 公開URL：https://wison-blip.github.io/tegakari-shiwake/
- 明細もプロフィールも、この端末のブラウザの中だけで扱います（外部への通信なし。ページの Content-Security-Policy で通信そのものを止めています）。
- 本ツールは明細の整理を補助するものです。経費への算入可否の判断は行いません。最終的な判断はご自身または税理士・税務署等にご確認ください。

## 使い方

1. 副業の内容を一言書くか、記入例を選びます。
2. カード・銀行のCSVを読み込みます。答えで区分が変わることだけを、最大3問たずねます。
3. 要判断を1件ずつ確定し、事業候補・私用候補は一覧で確定します。
4. 「日付・摘要・金額・ツール仕分け・最終区分・理由」の6列のCSVに書き出します。日付・摘要・金額は元の明細のまま、ツール仕分けは最初の判定のまま残し、本人の確定・記入・メモは理由の「確定：」以降に書きます。

## 乗車履歴と元明細の順番が違うとき

同日・同額で摘要と備考も同じ乗車2件は、利用番号などで元の行と対応づけてから用途を選びます。対応が分からなければ2行とも保留できます。片方の利用番号が届いたら、記録待ちの欄でその元行だけを開いてください。もう1件は自分の利用詳細が届くまで記録待ちに残ります。

## 利用番号を別の行に記録してしまったとき

記録待ちの欄で、確定済みの元行・区分・メモを利用詳細と見比べてください。行を取り違えていたら「確定した行の取り違えを直す」を開きます。記録待ちに戻す行と、区分・メモを移す先を確認して保存します。

架空明細24件で、6行目のH83（19時・家族との待ち合わせ）を5行目に私用で誤確定してから訂正しました。6行目に私用とH83が残り、5行目だけが記録待ちに戻りました。後日H27（14時・納品先からの帰路）を受け取り、5行目を事業に確定しました。

## 2件とも逆に確定し、CSV保存後に気づいたとき

同じブラウザで書き出し画面を開き、「保存後に乗車の取り違えに気づいたら」で利用詳細の元行・利用番号と確定内容を見比べます。対象の2行を選び、両方の「現在」と「訂正後」を読んでから入れ替えてください。「訂正版CSVを保存」で、名前の末尾に「_訂正1」が付いたファイルを保存できます。

複数組ある場合は「利用番号で探す」に、確定時のメモに書いた番号を入力します。「番号一致」が付くのは現在その番号を記録している行です。手元の利用詳細で正しい元行を確かめてください。同じ番号が複数組にあれば日付と行番号で選べます。「解除」で一覧に戻れます。

架空明細24件で、一覧の3組目（11月25日・21行目と22行目）を逆に確定してCSVを保存しました。番号K-742を入力すると、K-7420の別の組を除いて1組が表示されます。訂正版は21行目が事業のK-731、22行目が私用のK-742。差分は両行の最終区分と理由の4セルでした。

## 確定メモに利用番号がないとき

書き出し画面で利用詳細の日付・金額を選びます。時刻をメモしていたら乗車時刻も入力してください。時刻が片方のメモにある場合、前回保存した2行が並びます。手元の利用詳細でその時刻の元行を読み、該当する行を選んでください。両行の訂正案を確認してから保存できます。「資料で特定できない」も選べます。時刻も記録していない場合は、時刻を空欄にして、利用詳細の元行と用途を確認してください。対象の2件を開くと、訂正後の区分とメモを見ながら各行に利用番号を追記できます。

同じ架空明細24件で、初回の確定時には利用番号を記録せず、3組目を逆に確定してCSVを保存しました。11月25日・280円・19時を手がかりに、21行目に事業・K-731、22行目に私用・K-742を記録して再出力。初回CSVとの差分は両行の最終区分と理由の4セルでした。
