# てがかり仕分け

副業の明細（カード・銀行のCSV）を、副業の内容を手がかりに「事業候補・要判断・私用候補」に仕分け、本人が確定してCSVに書き出す、単一HTMLの整理ツールです。DMM 生成AI CAMP 第29回コンペの提出物です。

- 公開URL：https://wison-blip.github.io/tegakari-shiwake/
- 明細もプロフィールも、この端末のブラウザの中だけで扱います（外部への通信なし。ページの Content-Security-Policy で通信そのものを止めています）。
- 本ツールは明細の整理を補助するものです。経費への算入可否の判断は行いません。最終的な判断はご自身または税理士・税務署等にご確認ください。

## 使い方

開くと最初に、何ができるか・4つの手順・保存するCSVの列が出ます。「サンプルで試す」を押すと、配布の架空データ（ライターのプロフィールと、カード明細40件）で仕分けの結果まで進みます。

1. 副業の内容を一言書くか、記入例を選びます。
2. カード・銀行のCSV（Excelの .xlsx も可）を読み込みます。PDF・画像などは読み込まずに、CSVの取り出し方を案内します。答えで区分が変わることだけを、最大3問たずねます。
3. 要判断を1件ずつ確定し（画面下の「事業」「私用」）、事業候補・私用候補は一覧で確定します。
4. 「日付・摘要・金額・ツール仕分け・最終区分・理由」の6列のCSVに書き出します。日付・摘要・金額は元の明細のまま、ツール仕分けは最初の判定のまま残します。要判断を確定した行と候補から変えた行は理由の「確定：」に、本人の記入とメモは理由の最後に書きます。

書き出したCSVは、ふつう「ダウンロード」フォルダに保存されます。作業の続きはこのブラウザにだけ保存されるので、来年の明細や別のパソコンで使うときは、書き出し画面の「引き継ぎファイルを保存」でプロフィールと覚えた店を移せます。

## 同じ日・同じ運賃の乗車が2件あるとき

どちらの乗車か分からなければ、2件だけを保留して、ほかの明細を先に確定できます。利用詳細が届いたら、記録待ちの欄からその行だけを開いて確定します。書き出したあとで2件の取り違えに気づいたら、同じブラウザで書き出し画面を開き、「保存後に乗車の取り違えに気づいたら」で2件を入れ替えて、名前の末尾に「_訂正1」が付いた訂正版のCSVを保存できます。
